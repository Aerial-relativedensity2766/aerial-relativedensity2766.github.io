🚀 First Launch: Building Your First Truck Profile

When the toolkit opens for the first time, the workspace is empty and ready for you. Start with a truck profile, because almost everything else in the app links back to it.

  1. Select New Truck Profile from the main screen.
  2. Give the profile a name you will recognise — for example, the truck model plus a nickname.
  3. Fill in the fields you care about: make, configuration, current mileage estimate, and any notes.
  4. Save the profile. It appears in your profile list on the left side of the window.
  5. Repeat for each truck you own or plan to own.

You can edit any profile at any time. Nothing is permanent, so feel free to write rough notes first and refine them later.

🏢 Garage Planning and Upgrades

The garage planner is built around a simple idea: know what you own, know what you want next, and know how many trucks each location can hold. Open the garage tab and add a location for every city you are interested in.

  • Mark each garage as planned, purchased, or fully upgraded.
  • Set a target truck count so you can see at a glance which garages are underused.
  • Add short notes about why a location matters — for example, a strong cargo hub nearby.

The upgrade tracker works alongside your truck profiles. For each truck, open the upgrades panel and tick off what you have already installed. Remaining items stay visible as a checklist, which makes it much easier to decide what to save for next.

🗺️ Cargo Routes and Deliveries

Route planning is where the toolkit saves the most time. Instead of remembering a great route from weeks ago, store it properly.

  1. Open the cargo routes tab and choose Add Route.
  2. Enter the starting city and the destination city.
  3. Pick the cargo type from the list, or type your own description.
  4. Add notes about the route — tolls, tight delivery entrances, long straight stretches, or scenic sections you enjoy.
  5. Save the route so it appears in your route library.

When you complete a trip, log it in the delivery section. Record the distance, the cargo, and a quick personal rating. After a few weeks you will have a useful history that shows which routes you repeat most often and which ones are quietly worth more attention.

📊 Reading Your Driving Analytics

The analytics view turns your delivery log into simple summaries. You will see total distance recorded, average trip length, and a breakdown of cargo types you haul most often. There are no complicated settings — the numbers update as soon as you add or edit a delivery entry.

Use the analytics view to answer practical questions: which truck is doing the most work, which route type gives you the smoothest trips, and whether your average trip length is creeping upward as you gain confidence.
